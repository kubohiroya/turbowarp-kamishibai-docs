## このアプリは何？

TurboWarp紙芝居は、見る人も物語に参加できるデジタル紙芝居です。画面を見て楽しむだけでなく、
キーを押す、画面に触れる、カメラの前でポーズを取るといった行動を、物語の展開につなげられます。

たとえば、みんなで決めた選択によって次の場面を変えたり、登場人物を助けるポーズを取って物語を
先へ進めたりできます。カメラを使わず、キーやタッチだけで参加する作品も作れます。

作る人は、物語の台本と画像や音を組み合わせます。アプリ本体を作り替えなくても、作品ごとの台本と
素材を用意することで、新しい紙芝居を作れます。

## できること

| 楽しみ方         | できること                                                   |
| ---------------- | ------------------------------------------------------------ |
| 見る             | 絵、セリフ、音、画面効果を組み合わせた物語を楽しむ           |
| 操作して参加する | キーやタッチで選択し、物語を先へ進める                       |
| 身体で参加する   | カメラを使う作品では、ポーズを取って登場人物を助ける         |
| 作る             | 物語、登場人物、画像、音、参加方法を組み合わせて作品にする   |
| みんなで使う     | 授業、発表、読み聞かせ、ワークショップで役割を分担して楽しむ |

## 遊ぶ人の流れ

1. 遊びたい作品を開く
2. タイトルと、使う操作を確認して始める
3. 物語を見ながら、案内されたキー、タッチ、ポーズのいずれかで参加する
4. 最後まで見たら終了する

作品によって参加方法は異なります。ポーズがうまく認識されないときや、カメラを使いたくないときは、
作品に用意されたキーやタッチの操作を使います。操作せずに見るだけでもかまいません。

遊び始める前に、対象作品の版と、その作品で使う操作を確認してください。公開されている版については
「4.0の公開状況」で説明します。

## 作る人の流れ

作品作りは、最初からすべてを完成させる必要はありません。短い場面から始め、実際に動かしながら
少しずつ直していきます。

1. 誰に、どんな物語を届けたいか決める
2. 場面、登場人物、セリフ、参加方法を考える
3. 必要な画像や音を用意し、台本へまとめる
4. 作成中の確認画面（プレビュー）で、物語の進み方、見え方、音、操作を確かめる
5. 分かりにくいところや動かないところを直し、もう一度確かめる
6. 完成した作品を、本番で使う端末と会場で試す

台本に入力ミスがある、必要な画像が見つからないといった問題は、プレイを始める前に確認できます。
詳しい書き方やエラーの直し方は、台本作成ガイドで説明します。

## 人とAIの役割

このアプリでは、人、AI、アプリの役割を分けて考えます。AIに作品作りや利用の判断を任せきりにはしません。

| 担当   | 主な役割                                                           |
| ------ | ------------------------------------------------------------------ |
| 人     | 物語の目的、内容、参加方法、安全条件を決め、最後に結果を確認する   |
| AI     | 必要に応じて画像作りや、カメラ映像からポーズを見分ける作業を助ける |
| アプリ | 作った台本に沿って絵、セリフ、音を表示し、参加者の操作を受け取る   |

AIが作った画像や、カメラから判断したポーズは、間違うことがあります。作品へ採用するか、物語を先へ
進めてよいかは、人が確認して決めます。

## 安全に使うために

### カメラは使う前に確認する

カメラを使う作品では、何のために使うのか、どこまで映るのか、映像を保存したり外部へ送ったりするのかを、
参加者と保護者へ事前に説明します。使う端末、作品、会場ごとに設定を確認し、同意を得てから始めます。

カメラを使わないことも正式な選択肢です。参加したくない人や、身体を動かすことが難しい人のために、
キーやタッチで進める方法を用意します。

### AIが作った内容を人が確かめる

AIが作った画像や文章は、そのまま使わず、意図した内容か、誰かを傷つける表現や個人情報が含まれて
いないかを人が確認します。ポーズを見分ける機能も、照明、服装、背景、姿勢によって間違うことがあります。

### 会場で安全に動けるようにする

ポーズを取る場所の広さ、足元、周囲の人や物、画面の見やすさ、音量を本番前に確認します。困ったときに
すぐ止められる人を決め、カメラや音を止める手順も確認します。

## 教育・ワークショップでの利用

TurboWarp紙芝居は、物語作りと発表を、みんなで参加する活動にできます。

- **物語を考える:** 登場人物、出来事、選択、その結果を順番に整理する
- **役割を分ける:** 物語、絵、音、台本、動作確認、プレイを分担する
- **AIとの付き合い方を学ぶ:** AIの出力を人が確かめ、採用する理由を話し合う
- **発表へ参加する:** 代表者が操作し、ほかの人が展開を予想したり応援したりする
- **改善する:** プレイ後の感想をもとに、物語や参加方法を直す

国語、情報、総合学習、演劇的表現、地域紹介、外国語活動など、目的に合わせて取り入れられます。
カメラやAIを使うこと自体を目的にせず、学びたい内容と参加者の安全に合う方法を選びます。
