## 8月1日版との主な違い

| 観点             | 2026-08-01版（親子・小学生）                   | この下案（高校生）                                      |
| ---------------- | ---------------------------------------------- | ------------------------------------------------------- |
| 所要時間         | 110分（休憩10分を含む）                        | 40分（休憩なし）                                        |
| 参加単位         | 小学生と保護者のペア、2台                      | 高校生2人1組、1人1台（撮影時だけ役割交代）              |
| 題材             | 浦島太郎                                       | 真間の手児奈                                            |
| 台本形式         | YAML台本（行頭の`#`を外す）                    | ブロック台本（TurboWarp-Plus-Editor、DSL 4.0系）        |
| 生成AIでの作画   | 実習に含む（保護者が操作、約30分）             | **実習から外す**（仮の絵のまま進め、差し替えは任意）    |
| ポーズのクラス数 | 2〜4（`p1`〜`p4`）                             | 3（`stand`／`kime`／`rejected`）に固定                  |
| 実習の中心       | 画像生成 → コスチューム登録 → 台本修正         | 求婚者の考案 → ポーズ学習 → ブロック台本への組み込み    |

40分枠に収めるため、生成AIによる作画は実習から外しています。参加者は求婚者を自分で考え、
その人物が取る3つのポーズ（`stand`／`kime`／`rejected`）を**全員が自分のモデルとして新しく学習**し、
クラウドへエクスポートしたURLを台本の自分の席の枠へ書き入れます。絵は仮のまま進め、
差し替えは任意作業・発展課題（持ち帰り）として案内します。

## 未確定事項

この下案の段階で未確定・未着手の項目は、スタッフ向け資料の
「10. 未確定事項と準備タスク」に一覧でまとめています。主なものは次のとおりです。

- 開催日・会場・対象校・定員・ネットワーク環境

- 求婚者カタログの立ち絵・決めポーズ・断られた姿の画像一式
- 図版（スクリーンショット・会場見取り図・技術構成図）
- スタッフ向け資料（`tekona-workshop-staff.md`）の、参加者各自がモデルを作る方式への追従
  （タイムテーブル・配布資料フォルダ・事前準備・トラブルシューティング・救済手順）
- DSL 4.0 RC改訂の`forEach`で、型付き参照の解決がネストした値（`steps[].skin`など）まで及ぶかの確認
  （リポジトリ内のSchemaスナップショット2本では成立を確認済み。スタッフ向け資料10.3を参照）

## 公開導線について

`docs/config.mjs`の`workshopDocumentConfig`は、現在`workshops/2026-08-01`の1件だけを
対象にしています。この教材をHTML・PDFとして公開するには、複数ワークショップを扱えるよう
設定とビルド経路を拡張する必要があります。開催日が確定してから、別の作業として扱います。

`site/workshops/index.html`には、すでに「[準備中] 手児奈にプロポーズ！ AIと演じる参加型紙芝居」の
カードがDSL 4.0系の節に掲載されています。この下案の内容が確定したら、カードの記述
（対象年齢・所要時間・実習内容）と突き合わせてください。

## 権利表示の置き方について

すべてに`Copyright © 2026 Hiroya Kubo.`と`All rights reserved.`を要求します。

この下案は`docs/config.mjs`に登録していないため、本体（`tekona-workshop.md`）の

公開導線を整備して`workshopDocumentConfig`へ登録する際に、
8月1日版と同じ置き方（表紙のみ）へ戻すかどうかを決めてください。
