# 1. あなたの求婚者（参加者向け資料2.1）

**どの欄も40字までです。** ここに書いた言葉が、そのまま紙芝居の中に出ます。

| 項目                 | 記入例                               | あなたの答え |
| -------------------- | ------------------------------------ | ------------ |
| 求婚者の名前         | 塩焼きの若者                         |              |
| 求婚の言葉           | 海の塩で、一生あなたの食事を調えます |              |
| 手児奈の断りの言葉   | その塩は、村の人に分けてください     |              |
| 断られたときの一言   | 塩はまた焼けます。いつでも来ます     |              |
| 手児奈の心は揺れたか | 揺れた　／　揺れなかった             | 揺れた　／　揺れなかった |

**書くときの約束**

* 1つの欄は40字までです。
* 半角の`"`と`\`は使えません。台本の形がこわれます。
* 相手を見下したり、しつこく迫ったりする言葉は書かないでください。
* 身分や外見を書く欄はありません。人物の姿は、名前と求婚の言葉、そしてあなたのポーズで伝えます。

# 2. 3つのポーズ（参加者向け資料2.2）

AIに覚えさせるポーズは3つです。クラス名は**半角小文字でこのとおり**にします。

| クラス名   | いつの姿か       | AIが待つか     | どんな形にするか（自分用のメモ） |
| ---------- | ---------------- | -------------- | -------------------------------- |
| `stand`    | 登場したとき     | 待ちません     |                                  |
| `kime`     | 求婚をするとき   | **待ちます**   |                                  |
| `rejected` | 断られたとき     | **待ちます**   |                                  |

`kime`と`rejected`は、どんな形を取るのかを画面であなたの求婚者がしゃべります。
その説明も40字までで書いてください。これも台本に入る言葉です。

| 台本に書く説明               | 記入例                   | あなたの答え |
| ---------------------------- | ------------------------ | ------------ |
| 決めポーズの説明（`kime`）   | 壺を両手でささげ持つ     |              |
| 落胆のポーズの説明（`rejected`） | 肩を落としてうつむく |              |

**ポーズを決めるときの約束**

* 上半身だけで区別できる形にします（足だけが違う形・しゃがむ形は見分けられません）。
* 数秒そのまま止まれる形にします。
* 3つがはっきり違う形になるようにします。
* 相方にポーズを見てもらい、毎回同じ形が作れるか確かめます。

# 3. モデルのURL（参加者向け資料3.6）

「Export Model」→「Tensorflow.js」→「Upload my model」のあとに出てくるURLを、
**末尾の`/`まで**写してください。4章で、このURLを台本に入れます。

```text
https://teachablemachine.withgoogle.com/models/                                        /
```

ひかえ直すとき用（2回目）：

```text
https://teachablemachine.withgoogle.com/models/                                        /
```

**3章のチェック**

* [ ] クラスを3つにして、`stand`・`kime`・`rejected`と入力した
* [ ] 3つとも「Hold to Record」で5秒ほど撮った
* [ ] 「Train Model」を押して、トレーニングが終わった
* [ ] 「Preview」で、3つのポーズを取ってそれぞれのバーが100近くになった
* [ ] 「Upload my model」が終わり、URLを上の欄に写した（末尾の`/`も）
* [ ] Teachable Machineのタブを閉じていない
